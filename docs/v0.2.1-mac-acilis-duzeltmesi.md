# v0.2.1 — Mac çalışma ortamı açılışı

Kullanıcının Apple Silicon Mac'inde v0.2.0 içindeki Python çalıştırıcısı daha `print` çalışmadan `killed` ile kapanıyordu. conda-pack 0.8.1 `--dest-prefix` paketleme yolu Mach-O içeriğini değiştirirken imzasını yenilemiyordu.

v0.2.1, paketlemeden sonra çalışma ortamındaki Mach-O dosyalarını yerel ad-hoc imzayla yeniden imzalar ve her imzayı doğrular. Bu Apple Developer ID imzası veya noter onayı değildir. Başlatma hataları artık çıkış kodunu veya sinyalini de içerir.

Yeni Mac CI kontrolü gerçek PKG'yi `/Applications` içine kurar, Conda/Homebrew yolları olmadan kurulu çalışma ortamında CAD/PDF/OCR kontrolünü çalıştırır, kurulu masaüstü uygulamasını başlatır ve HTTP servisi ile ana sayfasını doğrular. Bu kontrol kullanıcıya ait Mac'in tüm grafik arayüz işlevlerinin testi yerine geçmez.

Apple Silicon kontrolü başarıyla geçti: https://github.com/ozlemergoterapi/kal-p-teklif/actions/runs/42295434494 . Windows paketi de üretildi; bu not yazılırken Intel Mac paketleme aşamasındadır. Yerelde 77 JavaScript testi geçti; CI'da 16 Python testi çalıştırıldı.
